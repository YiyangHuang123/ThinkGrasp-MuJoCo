Use Qwen3-VL's 0-to-1000 normalized relative coordinate system for all bounding-box and centroid coordinates, independent of the actual image resolution.

Perform the following steps:

Target Object Selection:

First determine whether the instructed target object is directly graspable.

If the target object is visible and can be safely grasped with sufficient free space for a parallel-jaw two-finger gripper, select the target object.

If the target object is visible but is obstructed, covered, tightly surrounded, or difficult to access safely, do not automatically select the target object. Instead, select the object or object part that most directly blocks access to the target and whose removal would most improve the target's graspability.

If the target object is not visible, select the object most likely to obstruct or cover the target, prioritizing objects whose removal would improve target visibility and access.

Prefer task-relevant obstruction removal over choosing an unrelated object that is merely easier to grasp.

If an object has a clearly visible part that provides a substantially safer or more reliable grasp, such as a handle, that object part may be selected.

Consider the geometric shape of the objects, local free space, collision risk, and suitability for a parallel-jaw two-finger gripper when selecting the target object or object part.

Output the name of the selected object or object part as [object:color and name] or [object part:color and name].

Treat spherical objects such as balls as round objects. Distinguish cups from mugs.

Selection Reason:

Briefly state why the selected object or object part was chosen.

Examples:
Selection Reason: target directly graspable
Selection Reason: obstruction removal; black cartridge blocks access to the white ramekin

Cropping Box Calculation:

Calculate a cropping box that includes the selected object and only nearby objects that may physically affect its grasping or removal.

The cropping box is a local planning context region and does not need to tightly match the selected object's exact boundary.

Provide the cropping box as (top-left x, top-left y, bottom-right x, bottom-right y), with every value expressed in the 0-to-1000 relative coordinate system.

Object Properties within Cropping Box:

For each object within the cropping box, provide the following properties:

Grasping Score:
Evaluate the ease or difficulty of grasping the object on a scale from 0 to 100, where 0 means extremely difficult and 100 means extremely easy.

Material Composition:
Evaluate the material composition of the object on a scale from 0 to 100, where 0 means extremely weak and 100 means extremely strong.

Surface Texture:
Evaluate the texture of the object's surface on a scale from 0 to 100, where 0 means extremely smooth and 100 means extremely rough.

Stability Assessment:
Assess the stability of the object on a scale from 0 to 100, where 0 means extremely unstable and 100 means extremely stable.

Centroid Coordinates:
Provide the visual center of the corresponding object or object part itself.

For the selected object, determine the centroid from its visible extent rather than from the cropping-box geometry or surrounding context.

The centroid may coincide with the cropping-box center when the selected object is genuinely centered there.

Preferred Grasping Location:
Divide the selected object's local grasping region into a 3x3 grid and return a number from 1 to 9 indicating the preferred grasping location:
1 = top-left
2 = top-center
3 = top-right
4 = middle-left
5 = center
6 = middle-right
7 = bottom-left
8 = bottom-center
9 = bottom-right

Choose the preferred grasping location based on visible geometry, local free space, collision risk, and suitability for a parallel-jaw two-finger gripper.
