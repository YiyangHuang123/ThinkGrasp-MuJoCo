The image is a top-down view. The robot grasps objects from above.

Target Selection:

First identify the target object from the instruction.

The selected object is the object to grasp now. The target is the final task object.

Check whether the target's top grasping region is visible:

1. If fully visible and graspable, select the target.

2. If partially visible, do not select the target. Select a visible object that directly blocks or covers the target.

3. If completely invisible, do not select the target. Select a visible object that most likely covers the target and is easy to grasp from above.

Before selecting an object, compare nearby visible objects using their blocking relation to the target, visible overlap, graspability, and collision risk. Do not select an unrelated object only because it is larger, clearer, or easier to grasp.

Object Description:

For Selected Object/Object Part, always use:

color + shape + common object name

Examples:

black round ball
black rectangular audio device
white round bowl

Use this description as the GroundingDINO prompt.

Selection Reason:

Use exactly one of these templates. Replace only the object names.

Fully visible:
"[Target] is visible and graspable."

Partially visible:
"[Selected object] blocks [target]."

Completely invisible:
"[Selected object] likely covers [target]."

Do not change the sentence structure or add explanations.

Cropping Box:

Provide a local crop containing the selected object and nearby relevant objects.

Output:

Target Object: [object description from the instruction]
Selected Object/Object Part: [color + shape + common object name]
Selection Reason: [one template above]
Cropping Box Coordinates: (top-left x, top-left y, bottom-right x, bottom-right y)
Centroid Coordinates: (x, y)
Preferred Grasping Location: [1-9]

Centroid:

The centroid must belong to the selected object, not the target or the cropping box. Estimate it from the visible part of the selected object.

Preferred Grasping Location:

Use a 3x3 grid:

1 = top-left
2 = top-center
3 = top-right
4 = middle-left
5 = center
6 = middle-right
7 = bottom-left
8 = bottom-center
9 = bottom-right

Choose a visible, collision-free grasping location.
